# Training modules and project alignment — 7 October 2026

The five local V2 training PDFs were extracted page by page (PHP 50 pages, SQL 46, DevOps 48, JavaScript 52, CSS & Styling Frameworks 52). Their chapter maps and relevant security, architecture, runtime, interaction and testing sections were reviewed for the session enhancement. This is a reference for future changes, not a claim that every exercise/tool in the curricula has been implemented.

Authority remains the official 19-page `Project Brief - Programmer.pdf`, then AGENTS, SDD and KNOWLEDGE. The PHP module includes Laravel/Eloquent examples, the JavaScript module includes React/Next.js, and CSS includes styling frameworks. Translate the principles into Native PHP OOP, PDO, custom CSS and Vanilla JS; those examples do not authorize changing the required stack. SQL examples must respect MySQL 8 semantics. Enterprise quality means explicit invariants and verified failure paths, rather than adding infrastructure without a justified need.
