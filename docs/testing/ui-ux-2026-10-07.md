# UI/UX fixes — 7 October 2026

Requirement IDs: UI-01, FIND-01, VIEW-01, TEST-01/03. Mandatory/Optional: UI polish of mandatory list/detail pages, requested by the user.

| Request | Change |
|---|---|
| Products table rounded, not attached to filters | Cause: the Import CSV dialog sat between `.filters` and `.table-scroll`, breaking the adjacency rule. Dialog moved after the table. Same defect found and fixed on Replenishment (helper text and selection form between filters and table; selection checkboxes now use the HTML `form` attribute and the actions follow pagination). |
| No underline on interactive text/buttons | Global `a { text-decoration: none }`. Because `--primary` (#16181D) is visually equal to body text (#202120), table links got a cue instead: "Review PO" uses `.action-link` like Open/Edit, and record links (product name, operation number) are semibold with a hover background. Keyboard focus ring unchanged. |
| Transaction Timeline placement | Moved from a loose paragraph below the actions into the page-header toolbar beside the back link on PO, SO and Stock Operation details. |
| Remove Order filter; sort with header arrows | The "Order" (Newest/Oldest) select was removed from PO and SO. Every data column header sorts the full filtered result server-side with ↕/↑/↓ (`aria-sort`, descriptive `aria-label`): PO/SO add supplier/customer and warehouse; Products add unit, purchase price and reorder point. Allow-listed keys only; unknown keys fall back to defaults. Filter forms keep the active sort as hidden fields. Client-side page sorting no longer attaches to Action, Select or blank headers. |
