## Remaining uncovered lines (33 statements, 0.58%)

These cannot be executed by any test. The owner decided on 9 October 2026 to keep them unchanged rather than modify production code for the percentage.

| Lines | Why unreachable | Kept because |

| `canRead()` false branch: CategoryService:61, CustomerService:26,35, SupplierService:26,35, WarehouseService:27,36, ProductService:72 | `AuthContext` rejects roles outside `User::ROLES`; `canRead()` is that same check | Defence in depth for authorization if roles change |

## Notes

- Two `CsvImport` parse-failure branches are reached through reflection (`parse('')`) and by temporarily unregistering the `php://` stream wrapper in a separate process.
- Running several Compose test projects at once exceeded Docker's ~4 GB memory and OOM-killed MySQL; run one quality job at a time.
